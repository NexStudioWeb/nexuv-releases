# NexUV releases

Public release channel for NexUV, NexStudio's one-click automatic UV unwrapping add-on for Blender.
This repository holds only the release ZIPs as release assets; there is no source code here.

- Product page and licence: https://nexstudio3d.com/nexuv
- Guide: https://nexstudio3d.com/nexuv/docs
- Support: support@nexstudio3d.com

Install: Blender > Edit > Preferences > Get Extensions > Install from Disk, then pick the ZIP for your system.
Every release lists the SHA-256 of each ZIP in SHA256.txt.

NexUV is licensed under the NexUV EULA (the add-on's Python bridge is GPL-3.0-or-later).
